# MOD-5 — BOARD

Доска объявлений (продажа животного — одного или нескольких — либо услуги)
и приватный чат с автором объявления. Первый модуль, специфицированный за
пределами только что закрытого [MOD-4](MOD-4-ANIMAL.md) (ANIMAL).

## Назначение

Публикация/редактирование/удаление объявлений, лента с поиском и фильтрами,
«Мои объявления», избранное, детальная карточка, чат (список чатов +
переписка, с автосозданием чата первым сообщением), звонок по телефону из
карточки/переписки, доступность всего раздела по стране пользователя.

## Состав

- Акторы: [ACTOR-1](../actors/ACTOR-1-USER-IN-AUTH.md) (переиспользован из
  AUTH — мутации: публикация/правка/удаление объявления, избранное, чат/
  сообщения, «Мои объявления»/«Избранное» как списки), [ACTOR-5](../actors/ACTOR-5-USER-IN-ANIMAL.md)
  (переиспользован из ANIMAL — чтение, доступное и гостю: лента, карточка
  объявления, звонок с карточки), [ACTOR-3](../actors/ACTOR-3-APP-IN-AUTH.md)
  (переиспользован из AUTH — реактивная проверка доступности раздела по
  стране).
- Сущности: [ENT-18](../entities/ENT-18-AD-IN-BOARD.md) (Ad), [ENT-19](../entities/ENT-19-CHAT-IN-BOARD.md)
  (Chat), [ENT-20](../entities/ENT-20-CHAT-MESSAGE-IN-BOARD.md) (ChatMessage).
- События: [EVT-68](../events/EVT-68-AD-PUBLISHED-IN-BOARD.md)…[EVT-80](../events/EVT-80-AD-CONTACT-CALLED-IN-BOARD.md)
  (`events/EVT-*-IN-BOARD.md`).
- Use-cases: `use-cases/UC-*-IN-BOARD.md` — см. индекс [use-cases/README.md](../use-cases/README.md).

## Граница — что модуль explicitly не владеет

- Справочники объявлений (типы/статусы/атрибуты/типы услуг) — используются
  только этим модулем, описаны как поля/связи внутри [ENT-18](../entities/ENT-18-AD-IN-BOARD.md),
  не как отдельные сущности (тот же паттерн, что у справочников вакцинации
  внутри `ANIMAL`/VAC).
- `Country.boardEnabled` — поле читается этим модулем (гейт доступности,
  [EVT-79](../events/EVT-79-BOARD-AVAILABILITY-CHECKED-IN-BOARD.md)), но сама
  сущность `Country` ([ENT-4](../entities/ENT-4-COUNTRY-IN-HANDBOOKS.md)) уже
  специфицирована модулем `HANDBOOKS` и не редактируется здесь.
- Виды/породы/масти животных, показываемые внутри карточки объявления, —
  модуль `HANDBOOKS` ([ENT-3](../entities/ENT-3-TAXONOMY-IN-HANDBOOKS.md));
  этот модуль только читает их по id для отображения.
- Сами животные, выбираемые для продажи (`AnimalIdentification`, поиск/
  автокомплит/сканирование в визарде создания объявления) — модуль `ANIMAL`,
  уже специфицирован; этот модуль лишь ссылается на них по id/номеру.
- Явный полный sync pass как таковой — модуль `SYSTEM` (последний в очереди),
  не здесь; синхронизация справочников BOARD — тот же факт, что и у
  справочников HANDBOOKS, не отдельное событие в этом модуле.
