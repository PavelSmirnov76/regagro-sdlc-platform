# EVT-59 — animal.child_linked

| | |
|---|---|
| Инициатор | [ACTOR-5](../actors/ACTOR-5-USER-IN-ANIMAL.md) |
| Модуль | [MOD-4](../modules/MOD-4-ANIMAL.md) |
| Сущность(и) | [ENT-11](../entities/ENT-11-ANIMAL-IN-ANIMAL.md) |

**Триггер.** На экране «Разведение» пользователь выбирает потомка из списка кандидатов (отфильтрованных по виду и правдоподобной дате рождения — моложе просматриваемого животного) и подтверждает; `ReproductionCubit.saveChild`.

**Эффект.** Изменяется запись ВЫБРАННОГО животного (потомка), не просматриваемого — его `motherId`/`fatherId` выставляются на просматриваемое животное, в зависимости от пола последнего; второй родитель потомка переносится из уже известного у просматриваемого животного второго родителя, если такой есть. Для синхронизированного потомка (`id >= 0`) взводится `needsUpdate: true`, тем же путём, что у [EVT-58](EVT-58-ANIMAL-PARENT-LINKED-IN-ANIMAL.md).

**Исходный код.** `lib/pages/reproduction/cubit/reproduction_cubit.dart` → `ReproductionCubit.saveChild`.
