# ENT-5 — DisposalReason

## Описание

Справочник причин выбытия животного (забой, гибель, продажа и т.п. — конкретный список задаётся сервером, не хардкожен в приложении), синхронизируется инкрементально.

## Поля

Стандартный набор справочника: `id`, `name`. Потребляется модулем выбытия (DISP, будет специфицирован позже) при выборе причины в визарде выбытия.

## Связи

Читается только модулем DISP (по id) — не владеет самим сценарием выбытия, только списком причин.

## Инварианты

Не редактируется локально — только синхронизация с сервера.
