# Реализовано

Единственный файл — `lib/repositories/disposal/disposal_repository.dart`:

- `getReportsFromApiAndSave` — при разборе каждой записи ответа
  `placeId` присваивается буквально `Value(e['from_place_id'] as int?)`
  (сырой JSON, не поле уже распарсенного `Disposal`, т.к. `Disposal.fromJson`
  ищет ключ `place_id`, которого сервер больше не присылает). `toPlaceId`
  заполняется автоматически через уже существующую в схеме
  `@JsonKey('to_place_id')`-аннотацию (`Disposal.fromJson`/
  `DisposalExtension.fromJsonRint`) — отдельного кода не потребовалось,
  колонка добавлена в `SHEEP-5-1`.
- `_enrichWithPlaceId` (обогащение через **текущее** `Animal.placeId`) —
  удалено целиком, единственный вызывающий код заменён на прямое
  присвоение внутри `.map()` при разборе ответа.
