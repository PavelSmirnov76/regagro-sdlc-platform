# SHEEP-5 — доработка выбытия (перемещение между фермами владельца)

Задача поставлена напрямую пользователем в сессии Claude Code 2026-07-20 (не экспорт
из трекера — в отличие от `SHEEP-4.md`). Записано дословно, без интерпретации.

## Постановка (как получена)

нужно доработать выбытия. Прогони задачу через sdlc таской SHEEP-5.

1. Сейчас причина выбытия "между фермами владельца" исключена id = 4. Нужно ее включить.
2. Если выбрана причина id=4. Дать пользователю следующими шагами выбор фермы farm и
   отделения place. выбор farm сделать через выпадающий список. place как стандартный
   шаг выбора place.
3. на Бэке добавили поле place_id в модель создания выбытия. Там указывается конкретное
   place_id назначения, если у нас перемещение между фермами.
   fromId и toId должны содержать remoteId фермы

Дальше нужно поправить отображение в календаре и получение с бэка. Вот модель с бэка:

Проблема отображения в календаре в том, что place_id не заполнен. Так как с бэка
приходит to_place_id и from_place_id. Давай просто при получении запонлять
place_id = from_place_id.

В данном примере АПИ from_place_id не пришло, потому что это устаревший запрос. Нас
это не волнует. Если null, пусть остаётся null и оно просто не отображается в
календаре. Это не проблема, так как нет прод пользователей.
