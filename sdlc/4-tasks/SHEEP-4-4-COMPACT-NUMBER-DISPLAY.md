# Компактный номер («…XXXX») в реестре животных и основном списке животных

## Объём

`AnimalCardWidget` (`lib/pages/animals/animals_page.dart:261-330`) —
используется и «Реестром животных» (`animals_registry_page.dart`), и
основным списком животных (`animals_page.dart`). Сейчас номер
(`animal.firstMainNumber`) — обычный `Text`, `maxLines: 2, overflow:
ellipsis`, занимает много места.

Расширить уже существующий `HighlightedNumber`-паттерн (сейчас два
почти идентичных приватных дубликата: `_HighlightedNumber` в
`lib/widgets/event_report/event_report_template.dart:180-210`,
`_HighlightedNumberText` в
`lib/pages/scanning/widgets/inventory_accordion_list_widget.dart:297-327`)
новым флагом `isShort`:
- `isShort: false` (по умолчанию, текущее поведение везде, где уже
  используется — отчёты по перемещению/вакцинации/выбытию, инвентаризация)
  — не меняется.
- `isShort: true` (новое) — вместо раскраски последних 4 цифр показывать
  только «…» + последние 4 цифры, остальное скрыто.

Применить `isShort: true` в `AnimalCardWidget` — оба экрана, один и тот же
виджет. Поскольку `AnimalCardWidget` становится третьим потребителем по сути
одного и того же паттерна — рекомендуется вынести общий (публичный) виджет
вместо третьей приватной копии; не обязательное требование, решает
исполнитель.

Полный номер по тапу — уже работает (переход в `AnimalCardPage`), доп. кода
не требуется. Критерии тикета про поиск/сортировку/фильтрацию по полному
номеру — неприменимы, такой функции в этих экранах нет.

Полное обоснование — `UC-312` (список), `UC-313` (реестр).

## Критерии приёмки (definition of done)

- [ ] В реестре животных номер отображается как «…» + последние 4 цифры.
- [ ] В основном списке животных — то же самое.
- [ ] Для номеров длиной ≤ 4 символа сокращение не применяется.
- [ ] Полный номер доступен по тапу на карточку (уже работает, регрессия исключена).
- [ ] Поведение `_HighlightedNumber`/`_HighlightedNumberText` в отчётах (`UC-309`/`UC-310`/`UC-311`) и инвентаризации (`UC-307`/`UC-308`) не меняется — там `isShort` остаётся `false`.

## Реализационные заметки

- Не создавать третий приватный дубликат раскрашивающего виджета — расширить существующий (по возможности вынести в общий публичный виджет для трёх мест использования).
- `AnimalCardWidget.firstMainNumber` — заменить прямой `Text(...)` на компактный виджет с `isShort: true`.
- Не трогать данные/фильтры/поиск — изменение чисто визуальное.
- Тестовые группы `test/pages/animals_bloc_test.dart` (`UC-71/72`) и `test/pages/animals_registry_cubit_test.dart` (`UC-73/74`) — дополнить/переименовать на `UC-312`/`UC-313` соответственно при реализации.
