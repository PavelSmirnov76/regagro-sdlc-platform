# SDLC-платформа REGAGRO Livestock

Общий, аудируемый **слой инструментов** над процессом SDLC приложения —
вынесен из репозитория приложения в отдельный репозиторий и **развёрнут на
сервере**, чтобы к нему из своего Claude подключались разные участники команды.
Содержит:

- **`sdlc/`** — дерево SDLC (PRD, бизнес-задачи, спеки, задачи, результаты …),
  каноничная копия. Живёт по строгому «закону» (`sdlc/AGENTS.md`): артефакты
  замораживаются при записи, «изменить» = выпустить новый id и **похоронить**
  старый, in-place правится только PRD.
- **`mcp/`** — Python MCP-сервер (`sdlc-mcp`), которым управляет Claude — из
  **claude.ai** (кастомный коннектор по HTTPS+токен) или из локального
  **Claude Code** (stdio). Он предоставляет инструменты над `sdlc/`, **сторожит
  закон** и **аудирует каждое изменение** (кто/что/когда), плюс ведёт транскрипт
  сессии. Внешние действия (PR, сборка APK, доставка в Telegram) — интерфейсы с
  фейками, реальные вызовы включаются добавлением ключей.
- **`docs/`** — установка, архитектура, TDD, аудит.

Приложение остаётся в `AGROSERVIS-MOBILE/agro_system` — MCP делает туда PR и
собирает APK; сюда его код не копируется.

## Модель

Мозг — это **уже существующий Claude**, к которому подключается участник: из
**claude.ai** (кастомный коннектор, HTTPS + токен в URL) или из локального
**Claude Code** (stdio). MCP — это **общий слой инструментов**, а не агент и не
отдельная «нейронка»: «получает запрос, задаёт вопросы, ведёт по SDLC, правит
код, делает PR и APK» — всё это делает сам Claude, вызывая инструменты сервера.
Сервер даёт структурированные, аудируемые операции и промпты-воркфлоу
(`run_pass`, `new_feature`, `tdd_task`), общие для всех подключившихся.

## Быстрый старт (локально, для разработки самого MCP)

```bash
cd mcp
uv sync                      # поставить зависимости (Python 3.11)
uv run pytest                # прогнать тесты
uv run python scripts/smoke.py   # end-to-end смоук по stdio
uv run sdlc-audit history    # история изменений
```

## Подключение

- **claude.ai (общий сервер).** Развёрнутый на сервере MCP отдаётся по HTTPS с
  токен-гейтом; участник добавляет его в claude.ai → Settings → Connectors как
  кастомный коннектор по URL `https://<домен>/sse?token=<токен>`. Деплой
  (systemd + nginx + TLS) и получение URL — в [`docs/SETUP.md`](docs/SETUP.md), раздел 6.
- **Claude Code (локально, stdio).** Регистрация подпроцессом — там же, раздел 3.

Ключи для реальных PR/Telegram/APK — [`docs/SETUP.md`](docs/SETUP.md), раздел 4.
Архитектура — [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

> На этой машине `~/.local` принадлежит `root`, поэтому рядом лежит
> машинно-специфичный `mcp/uv.toml` (в `.gitignore`), указывающий uv на writable
> кэш и системный Python 3.11 (Homebrew). На нормальной машине он не нужен.
